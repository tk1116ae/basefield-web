BASE FIELD

プライバシーポリシー

BASE FIELDは、草野球チームのスコア入力、成績管理、選手管理を行うためのアプリです。本ポリシーでは、アプリで扱う情報とその管理について説明します。

最終更新日: 2026年7月8日
運営者: Tatsuki Nagashima
問い合わせ先: royalhoneys2026@gmail.com

1. 取得する情報

BASE FIELDでは、ユーザーがアプリ内で入力または選択した情報を、アプリの機能提供のために扱います。具体的には、以下の情報を扱う場合があります。

  • チーム名、チーム設定、シーズン情報
  • 選手名、背番号、守備位置、プロフィール、選手画像などの選手情報
  • 試合日、対戦相手、球場名、試合種別、スコアなどの試合情報
  • 打順、守備位置、出場選手、打撃成績、投手成績、守備に関する記録などの成績情報
  • チームログイン、招待、権限管理などに関する情報
  • ユーザーが任意で追加した写真、画像、メモ、設定情報
  • BASE FIELD Proの購入状態など、アプリ内課金の利用状況

2. 利用目的

取得した情報は、以下の目的で利用します。

  • チーム、選手、試合、成績を保存・表示・編集するため
  • 打率、OPS、防御率、WHIP、ランキングなどを集計するため
  • チームメンバーが必要な情報を確認できるようにするため
  • CSV出力、共有カード作成、スコアシート管理などの機能を提供するため
  • BASE FIELD Proの利用可否を判定するため
  • 問い合わせ対応、不具合調査、サービス改善のため

3. 第三者提供

BASE FIELDは、法令に基づく場合、ユーザーの同意がある場合、またはサービス提供に必要な範囲で外部サービスを利用する場合を除き、ユーザーの情報を第三者へ販売または提供しません。

広告目的の第三者トラッキングは行いません。また、第三者広告配信のためにユーザー情報を利用することはありません。

4. 決済情報について

BASE FIELD Proのアプリ内課金は、AppleのStoreKitおよびApp Storeの決済システムを利用して処理されます。BASE FIELD側では、クレジットカード番号、セキュリティコード、銀行口座情報などの決済情報を取得または保持しません。

BASE FIELD Proは、購入したApple ID単位で有効になります。現時点では、Supabase上のチーム単位課金やチーム全体でのPro共有とは連携していません。

5. データの保存・管理

BASE FIELDは、端末内の保存領域およびバックエンドサービスとしてSupabaseを利用して、チーム情報、選手情報、試合情報、成績情報、ログイン関連情報などを保存・管理する場合があります。

データは、アプリ機能の提供に必要な範囲で管理します。ユーザー自身がCSV出力や共有機能を利用した場合、そのファイルや共有先での管理はユーザーの操作と共有先の環境に従います。

6. ユーザーによる問い合わせ・削除依頼

登録情報の確認、修正、削除に関する相談は、問い合わせ先までご連絡ください。本人確認や対象チームの確認を行ったうえで、合理的な範囲で対応します。

チームデータは、チーム管理者または権限を持つメンバーによって編集・削除される場合があります。チーム内で共有されている情報については、必要に応じてチーム管理者にもご相談ください。

7. 子どもの利用について

BASE FIELDは、草野球チームの運営者やメンバーによる利用を想定したアプリです。未成年の方が利用する場合は、保護者またはチーム管理者の確認のもとで利用してください。

未成年の個人情報が不適切に登録されていると思われる場合は、問い合わせ先までご連絡ください。

8. セキュリティ

BASE FIELDは、扱う情報を適切に管理するよう努めます。ただし、インターネット通信や端末の利用環境において、完全な安全性を保証するものではありません。端末のロック、OSの更新、共有範囲の確認など、ユーザー側でも安全な利用にご協力ください。

9. 改定について

本ポリシーは、アプリの機能追加、利用サービスの変更、法令改正などに応じて改定する場合があります。重要な変更がある場合は、アプリ内または公式サイト上で分かりやすくお知らせします。
