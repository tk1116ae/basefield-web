BASE FIELD

利用規約

本規約は、草野球チーム向けスコア入力・成績管理アプリ「BASE FIELD」の利用条件を定めるものです。

最終更新日: 2026年7月8日
運営者: Tatsuki Nagashima
問い合わせ先: royalhoneys2026@gmail.com

1. サービス概要

BASE FIELDは、草野球チーム向けに、チーム作成、選手管理、試合作成、スコア入力、打撃成績・投手成績の入力、ランキング表示、CSV出力などを提供するアプリです。

本アプリは、試合後に紙のスコアシートなどを見ながら成績を整理し、チーム内で記録を見返しやすくすることを目的としています。

2. 利用条件

ユーザーは、本規約および関連する法令、App Storeの規約に従ってBASE FIELDを利用するものとします。未成年の方が利用する場合は、保護者またはチーム管理者の確認のもとで利用してください。

ユーザーは、入力する情報について、必要な権利または許可を持っているものとします。チームメンバーの名前、写真、プロフィールなどを登録する場合は、チーム内で適切に確認してください。

3. アカウント・チームデータの管理

ユーザーは、チーム情報、選手情報、試合情報、成績情報、ログイン情報などを正確かつ適切に管理する責任を負います。

チーム管理者は、チームメンバーの招待、編集権限、データの修正・削除について、チーム内で適切に運用してください。BASE FIELDは、チーム内の記録内容や権限管理に関する当事者間のトラブルについて、原則として責任を負いません。

4. 禁止事項

ユーザーは、以下の行為を行ってはなりません。

  • 虚偽または不正確な情報を悪意をもって登録する行為
  • 他人の個人情報、写真、成績などを無断で公開または共有する行為
  • 第三者の権利、名誉、信用、プライバシーを侵害する行為
  • 法令または公序良俗に反する行為
  • アプリ、サーバー、ネットワークに過度な負荷をかける行為
  • 不正アクセス、リバースエンジニアリング、改ざん、脆弱性の悪用などの行為
  • BASE FIELDの運営を妨げる行為

5. BASE FIELD Proの課金条件

BASE FIELD Proは、アプリ内課金によって提供される有料プランです。Proでは、ランキング全件表示、選手詳細の拡張、CSV出力、チーム名入りスコアシートのPDF／PNG保存などの機能を利用できます。

料金は、月額900円または年額8,800円です。実際の価格、期間、課金条件は、App Store上で表示される内容が優先されます。

Product IDは、月額プランが jp.basefield.team.pro.monthly、年額プランが jp.basefield.team.pro.yearly です。

BASE FIELD Proは、App Storeで購入した場合、購入したApple ID単位で有効になります。これとは別に、開発協力チーム、運営チーム、特別に許可したチームなどに対して、BASE FIELD側の判断で運営付与プランを設定する場合があります。運営付与プランはAppleの自動更新サブスクリプションではなく、請求、解約、返金は発生しません。現時点では、ユーザーが任意にチーム単位の有料契約を購入する機能や、購入したApple IDのサブスクリプションをチーム全体へ共有する機能は提供していません。

6. 自動更新サブスクリプションについて

BASE FIELD Proは、自動更新サブスクリプションです。無料トライアルやキャンペーンが提供される場合を除き、購入時に選択した期間ごとにApple IDへ課金されます。

サブスクリプションは、現在の期間が終了する24時間以上前に解約しない限り、自動的に更新される場合があります。更新や請求の詳細は、AppleのApp StoreおよびApple IDの管理画面で確認できます。

7. 解約方法

BASE FIELD Proの解約は、iPhoneまたはiPadの「設定」アプリからApple IDのサブスクリプション管理画面を開き、BASE FIELD Proを選択して行ってください。

アプリを削除しただけでは、サブスクリプションは自動的には解約されません。必ずApple IDのサブスクリプション管理画面で解約手続きを行ってください。

8. 返金について

BASE FIELD Proの購入、請求、返金はAppleの規約と手続きに従います。返金を希望する場合は、Appleの購入履歴またはAppleサポートから申請してください。BASE FIELD側でApple IDの決済情報を保持していないため、直接返金処理を行うことはできません。

9. 免責事項

BASE FIELDは、入力されたスコア、成績、ランキング、集計結果について、常に完全な正確性を保証するものではありません。ユーザーは、必要に応じて入力内容や集計結果を確認してください。

通信環境、端末の状態、外部サービスの障害、アプリの不具合などにより、データの表示、保存、同期、共有が正常に行われない場合があります。重要なデータは、必要に応じてCSV出力などでバックアップしてください。

BASE FIELDの利用によりユーザーまたは第三者に生じた損害について、運営者に故意または重大な過失がある場合を除き、運営者は責任を負わないものとします。

10. サービス変更・終了

BASE FIELDは、機能の追加、変更、一時停止、終了を行う場合があります。重要な変更がある場合は、アプリ内または公式サイト上で分かりやすくお知らせします。

11. 規約変更

本規約は、アプリの機能追加、課金内容の変更、利用サービスの変更、法令改正などに応じて改定する場合があります。改定後の規約は、公式サイトまたはアプリ内に掲載した時点で効力を持つものとします。
