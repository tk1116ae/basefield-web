BASE FIELDを使い始める

アプリの最初の画面で、代表者は「チームを作る」、既存チームへ参加する方は「コードで参加」を選択してください。完成形を先に確認したい場合は「30秒デモを見る」を利用できます。

チーム共有・ログイン

ログインや復帰がうまくいかない場合は、次の内容を確認してください。

  • チーム参加用のTコード、または選手本人リンク用のMコードが正しいか
  • 代表者または管理者がメンバー承認と選手リンクを完了しているか
  • アプリで正しいチームを選択しているか
  • 通信環境が安定しているか

Tコードは参加申請、Mコードは発行済み選手への直接リンクに使います。Mコードは一度限りで有効期限があります。代表者・管理者が復帰する場合は、登録メールアドレスへ届く確認コードを利用してください。参加者へ共通PASSの入力は求めません。

データの保存とバックアップ

BASE FIELDは端末内データを優先し、チーム共有を利用する場合は必要な変更をSupabaseへ同期します。BASE FIELD Proでは、設定画面のCSV出力から大切な記録を手元へ書き出せます。

BASE FIELD Pro

App Storeで購入したBASE FIELD Proは、購入したApple IDで利用できます。購入済みなのにPro機能を利用できない場合は、設定画面の「購入を復元」を実行してください。

解約や請求の確認は、iPhoneまたはiPadの「設定」からApple IDのサブスクリプション管理画面を開いて行ってください。

登録情報の削除

チームや試合など、アプリ内で削除できるデータは各編集画面から削除できます。共有データの削除や個別対応が必要な場合は、対象チーム名と内容を添えてお問い合わせください。本人確認またはチーム管理権限の確認をお願いする場合があります。

不具合を報告する

次の情報を分かる範囲で添えていただくと、確認がスムーズです。

  • 端末名とiOSバージョン
  • BASE FIELDのバージョンとビルド番号
  • 問題が起きた画面と操作手順
  • 表示されたエラーメッセージ
  • 可能であればスクリーンショット
